Common issues

Fix by symptom

Problem What to do Why it happens
CUBY becomes silent after a few commands Say calibrate microphone, reduce background noise, then restart Start AI if needed. The recognizer can adapt to fan/noise levels and raise the energy threshold too high.
Wake word works only in English Start with Hey CUBY, then say switch to Tamil. Startup resets to English by design. Default startup language is English so the assistant has a predictable first wake flow.
Tamil is understood but replies are not Tamil Say switch to Tamil language. If TTS fails, check internet because Tamil neural voice may need online synthesis. Tamil voice uses Edge/gTTS-style playback when available and falls back to installed system voice.
Cannot switch back to English Say switch to English, English language, or type it in the command box. Tamil speech may be transcribed as Tanglish; typing once is the quickest reset.
Spotify opens but wrong song plays Use a complete title and artist: open Spotify and play New York Nagaram A R Rahman. Spotify ranking can show videos, playlists, or old queue items before the exact song.
Gmail or Calendar asks for permission Complete Google sign-in. If Calendar shows API disabled, enable Google Calendar API in the Google Cloud project and retry. Google tools require OAuth and the correct API to be enabled for your credentials.
Weather gives the wrong city Say the city last and clearly: weather tomorrow in Trichy. Update WEATHER_ALERT_CITY if needed. Short city names and mixed-language phrases can be mis-parsed without a clear location.
Power-cut official page needs confirmation Say confirm official power cut in Karumandapam, enter the TNPDCL captcha manually, and submit. TNPDCL uses captcha. CUBY can guide and read results, but it will not bypass captcha.
Water-cut alert not found Try water cut in Ponnagar and check the source list. Use Corporation helpline if no online notice exists. Water interruptions are not always published in a machine-readable official page.
News count is not respected Say top 20 Indian news or top 10 Trichy politics news. Dynamic news routing needs a count and topic/location phrase to avoid generic headlines.
Naukri auto-apply does not submit jobs Use CUBY to open guided searches, then review and submit applications yourself. Final application submission is sensitive and remains human-controlled.
Playwright official confirmation is unavailable Run python -m playwright install chromium inside the venv if the browser engine is missing. The Python package and browser engine are separate installs.

Use the command box on the home screen for long mail, job, calendar, or mixed Tamil-English commands.
